# Бобуслуги

Госуслуги для вымышленной планеты **Асей**: гражданство, Бобопаспорт, визы, штрафы в псякоинах, письма президенту, выборы и розыск банд.

- **Сайт** — React + Vite + Tailwind, лежит на **GitHub Pages**.
- **База и аккаунты** — **Supabase** (бесплатный тариф). Вся логика — в SQL-функциях и правилах доступа (RLS) в `supabase/migrations/`.

## Что умеет

| Раздел | Возможности |
|---|---|
| Аккаунты | Вход по логину и паролю, код-приглашение, **первый зарегистрированный — суперадмин** |
| Гражданство | После регистрации гражданства нет. Получение, смена, вид на жительство |
| Документы | Бобопаспорт, загранпаспорт, права, ПСЯЛС, визы. Номера только из лорных чисел |
| Переезд | Визы, доставка по реке Саменка, Мигрантское окно (нужна виза Бобостана) |
| Обращения | Письмо президенту (его видит только президент), жалоба на банду |
| Псякоины | Выдают президент (своим гражданам) и админ. Пошлины списываются при подаче и возвращаются при отказе |
| Штрафы и налоги | Выписывают чиновники, оплата с баланса, список должников |
| Запрещённые слова | 52, 1488, 67, 42, «Свастон» в любом поле, в том числе «5 2», «с в а с т о н» и латиницей: форма не отправляется, приходит автоштраф |
| Новости и указы | Указ президента рассылает уведомления всем гражданам |
| Выборы | Кандидаты, голосование (один раз, только граждане), итоги после закрытия |
| Розыск | Доска «Разыскиваются» и должники по штрафам |
| Госслужба | Очередь заявлений своей страны, граждане, штрафы, новости, выборы, розыск |
| Админка | Роли, баны, гражданство, балансы, код-приглашение, пошлины, журнал действий |
| Язык | Переключатель RU / Псянский. В псянском режиме дата всегда 12.34.1234, а числа только 123/321/1234/4321 |

Роли: **Гражданин**, **Чиновник** (рассматривает заявления своей страны), **Президент** (плюс указы, выборы, псякоины, назначение чиновников), **Суперадмин**.

## Запуск в интернете (GitHub Pages + Supabase)

### 1. Supabase

1. Создайте проект на [supabase.com](https://supabase.com).
2. **Authentication → Sign In / Providers → Email**: выключите **Confirm email**. Логины превращаются в служебные адреса `логин@bobuslugi.local`, писем туда никто не шлёт.
3. Примените схему базы одним из двух способов:
   - **Вручную**: откройте **SQL Editor**, вставьте содержимое `supabase/migrations/20260928000001_init.sql` и нажмите Run.
   - **Автоматически при деплое**: см. шаг 2.
4. **Project Settings → API**: скопируйте **Project URL** и ключ **anon / publishable**. Этот ключ публичный: он и так виден в браузере, всё защищено правилами доступа в базе.

### 2. GitHub

1. **Settings → Pages → Source**: выберите **GitHub Actions**.
2. **Settings → Secrets and variables → Actions → Variables** — добавьте:
   - `VITE_SUPABASE_URL` — Project URL;
   - `VITE_SUPABASE_ANON_KEY` — anon/publishable ключ;
   - (необязательно) `VITE_EMAIL_DOMAIN` — если Supabase не принимает домен `bobuslugi.local`, укажите любой свой домен.
3. (Необязательно) Чтобы миграции применялись сами: добавьте переменную `SUPABASE_PROJECT_REF` (id проекта из адреса) и секреты `SUPABASE_ACCESS_TOKEN` ([токен](https://supabase.com/dashboard/account/tokens)) и `SUPABASE_DB_PASSWORD`.
4. Влейте код в ветку `main` или запустите workflow **«Деплой на GitHub Pages»** вручную. Сайт появится по адресу `https://<владелец>.github.io/<репозиторий>/`.

### 3. Первый вход

1. Зарегистрируйтесь первым: вы станете **суперадмином**.
2. В **Админка → Настройки** задайте **код-приглашение** и раздайте его друзьям. Пока код пустой, зарегистрироваться может любой.
3. Назначьте президентов стран (**Админка → Пользователи → Роль**) и выдайте им гражданство.

## Локальная разработка

Нужны Node.js 22 и Docker.

```bash
npm install
npm run db:start            # локальный Supabase (адрес и ключи выведет в конце)
cp .env.example .env.local  # впишите VITE_SUPABASE_ANON_KEY из вывода `npx supabase status`
npm run dev                 # http://localhost:5173
```

Изменили схему — добавьте новый файл в `supabase/migrations/` и выполните `npm run db:reset`.

## Тесты

```bash
npm run typecheck   # типы
npm test            # юнит-тесты лорных правил
npm run test:db     # тесты базы: права доступа, заявления, псякоины, автоштрафы, выборы (нужен db:start)
npm run e2e         # сценарий в браузере через Playwright (нужен db:start и .env.local)
```

Тесты базы и e2e **очищают локальную базу** перед запуском. CI (`.github/workflows/ci.yml`) прогоняет всё это на каждый push.

## Устройство

```
supabase/migrations/   схема, RPC-функции, RLS
src/lib/               клиент Supabase, авторизация, i18n (ru/psy), лорные правила, запросы
src/lib/services.ts    описание услуг для интерфейса (поля форм, подсказки)
src/pages/             страницы: главная, услуги, кабинет, госслужба, админка, новости, выборы, розыск, страны, лор
tests/                 unit, db, e2e
```

- Таблицы доступны пользователям **только для чтения**. Любое изменение идёт через функцию (`submit_application`, `review_application`, `grant_coins`, …), а она проверяет роль, страну, баланс и запрещённые слова.
- Баланс меняется только в `private.move_coins`, каждая операция пишется в журнал `transactions`.
- Используется `HashRouter` (адреса вида `/#/cabinet`): GitHub Pages не умеет перенаправлять пути на `index.html`.
- Новая услуга: строка в таблице `services` (в миграции), условия и последствия одобрения в `submit_application` и `review_application`, описание полей в `src/lib/services.ts`, тексты в `src/lib/i18n/ru.ts` и `psy.ts`.
