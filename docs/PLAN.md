# Бобуслуги — план разработки

> **Изменение архитектуры.** По просьбе пользователя хостинг — **GitHub Pages + Supabase**, а не Next.js на Vercel.
> Сайт — статическое SPA (Vite + React). Серверная логика — SQL-функции и RLS в Supabase (`supabase/migrations/`).
> Все 9 этапов реализованы в первой версии. Актуальное описание — в `README.md`.

## Контекст
Делаем «Госуслуги» для вымышленной планеты Асей (лор: https://volcano-structure-35d.notion.site/34c969ffd00480c4bf5dd8c4cd50c4f0).
Репозиторий `bobopsya/bobuslugi` пустой, ветка `claude/gifted-planck-ydloji` — начинаем с нуля.

Решения, принятые с пользователем:
- Рабочий сайт с аккаунтами для компании друзей (до ~50 человек).
- Стек: Next.js + Vercel + Postgres. Вход по логину и паролю.
- Все услуги в MVP: документы, штрафы и налоги, переезд и гражданство, обращения и выборы.
- Валюта — **псякоины**. Их выдаёт только админ или президент, перевода между игроками нет.
- Заявления рассматривает человек (чиновник, президент, админ).
- Переключатель языка RU / Псянский. В RU обычные числа и даты. В псянском режиме числа только 123/321/1234/4321, а дата всегда 12.34.1234.
- Запрещённые слова и числа (52, 1488, 67, 42, «Свастон»): форма не отправляется, человек получает автоматический штраф.
- Роли: Гражданин, Чиновник страны, Президент, Суперадмин.
- Дизайн: пародия на Госуслуги. Сине-белая гамма, но свой логотип и свой герб, реальные логотипы не копируем.
- После регистрации у человека **нет гражданства**. Первая услуга — «Получение гражданства».
- Дополнительно: новости и указы, уведомления на сайте.
- Раздел «Розыск»: только банды (Балсас, Писяганг), хакеры Жуконета, вымышленные злодеи и должники по штрафам. Часть лора «СтопДЦП» с реальными именами в сайт **не переносим**.

## Стек
- **Next.js 15 (App Router, TypeScript)**. Server Actions для форм.
- **Tailwind CSS**, компоненты shadcn/ui.
- **Prisma + Postgres (Neon через Vercel Marketplace)**.
- **Авторизация**: своя, на сессиях в БД. Пароль хэшируется argon2 (`@node-rs/argon2`), сессия хранится в httpOnly-cookie. Для регистрации нужен код-приглашение из переменной `REGISTRATION_CODE`, чтобы не зашли посторонние. Попытки входа ограничены (rate limit).
- **Zod** проверяет формы, **next-intl** отвечает за RU/PSY.
- Тесты: **Vitest** (юнит-тесты) и **Playwright** (e2e, Chromium уже есть в окружении).
- CI в GitHub Actions: lint, typecheck, vitest, build. Деплой — Vercel через интеграцию с Git.

## Структура проекта

```
    (cabinet)/services/  каталог услуг и [serviceCode]/ — форма услуги
    (gov)/gov/           кабинет чиновника или президента: очередь заявлений, штрафы, новости, выборы, розыск

  lib/

```

## Модель данных (Prisma)
- **User**: login, passwordHash, displayName, role (`CITIZEN | OFFICIAL | PRESIDENT | SUPERADMIN`), `countryId?` (гражданство; при регистрации пустое), `govCountryId?` (какой стране служат чиновник или президент), balance (Int), bannedAt?
- **Session**: id, userId, expiresAt.
- **Country**: code (`BOBO`, `SSHP`, `BOBOSTAN`, `PONOSSO`, `INDUSIA`), name, psyName, capital, cities[], leaderTitle, описание из лора. Заполняется через seed.
- **Application** (заявление): userId, serviceCode, targetCountryId, data (Json), status (`SUBMITTED | NEEDS_INFO | APPROVED | REJECTED`), reviewerId?, reviewerComment?, feePaid.
- **Document**: userId, type (`PASSPORT | INTL_PASSPORT | DRIVER_LICENSE | PSYALS | RESIDENCE_PERMIT | VISA`), countryId, number (генерируется, например `1234 321123`), validUntil?, revokedAt?, applicationId.
- **Fine**: userId, countryId, amount, reason, kind (`FINE | TAX | AUTO_FORBIDDEN`), status (`UNPAID | PAID | CANCELLED`), issuedById?
- **Transaction**: журнал всех движений псякоинов. userId, delta, type (`GRANT | FEE | FINE_PAYMENT | REFUND`), refType/refId, actorId. Баланс меняется только через `lib/economy/ledger.ts` внутри `prisma.$transaction`.
- **News**: countryId? (пусто = новость для всей планеты), authorId, kind (`NEWS | DECREE`), title, body.
- **Election / Candidate / Vote**: у Vote уникальный ключ (electionId, userId). Голосовать могут только граждане страны.
- **WantedEntry**: name, description, reward, countryId, imageUrl?, `linkedUserId?` (для должников), active.
- **Notification**: userId, type, payload Json, readAt?
- **AuditLog**: действия чиновников и админа (одобрил, выдал деньги, сменил роль).

## Реестр услуг (`lib/services/registry.ts`)
Каждая услуга описывается одной записью: `code, category, titleKey, formSchema (zod), fee, requires(user) → ok | причина, onApprove(tx, app)`. Каталог, форма, валидация и одобрение строятся из этого реестра. Новая услуга = новая запись.

| Категория | Услуга | Условие | При одобрении |
|---|---|---|---|
| Гражданство | Получение гражданства | без гражданства | `user.countryId` задаётся, выдаётся Бобопаспорт |
| Гражданство | Смена гражданства | есть гражданство | старый паспорт аннулируется, выдаётся новый |
| Гражданство | Вид на жительство | без гражданства или иностранец | Document RESIDENCE_PERMIT |
| Документы | Загранпаспорт | есть паспорт | Document INTL_PASSPORT |
| Документы | Водительские права (Гармод) | есть паспорт | Document DRIVER_LICENSE |
| Документы | ПСЯЛС | есть паспорт | Document PSYALS |
| Переезд | Виза (СШП / Бобостан / …) | есть загранпаспорт | Document VISA |
| Переезд | Доставка по реке Саменка | гражданин | только статус и комментарий |
| Переезд | Проход через Мигрантское окно | виза Бобостана | лорная пасхалка, только статус |
| Обращения | Письмо президенту | гражданин | ответ президента в комментарии |
| Обращения | Жалоба на банду | гражданин | чиновник может создать WantedEntry |

Если услуга платная, пошлина списывается при подаче. При отказе деньги возвращаются (REFUND).
Кто рассматривает: чиновник или президент страны `targetCountryId`, суперадмин видит всё.

## Лорные правила (`lib/lore/*`)
- `forbidden.ts`: приводит текст к нормальному виду (нижний регистр, латинские буквы-двойники → кириллица, убирает пробелы и точки между цифрами). Затем ищет в последовательностях цифр `52 | 1488 | 67 | 42`, а в словах — «свастон». Проверка встроена в общий хелпер Server Action для **всех** пользовательских полей: формы услуг, новости, обращения, имя пользователя. Если найдено совпадение, текст отклоняется и создаётся Fine `AUTO_FORBIDDEN` (сумма в конфиге, например 123). Пользователь получает уведомление. Разрешённые лорные числа 123/321/1234/4321 запрещённых сочетаний не содержат — это закроем тестом.
- `numbers.ts`: `formatNumber(n, locale)`. В RU показывает число как есть. В PSY детерминированно превращает его в одно из 123/321/1234/4321, а реальное значение остаётся в БД.
- `dates.ts`: `formatDate(d, locale)`. В PSY всегда `12.34.1234`.
- Псянский словарь из лора (кси, паса, сапс, пеж, асей, га, сиф…) — в `psy.json`. Интерфейс в псянском режиме переводится вручную, без машинного перевода.

## Роли и доступ
`requireRole()` / `requireCountryStaff(countryId)` проверяются на сервере в каждом action и layout.
- Гражданин: подаёт заявления, платит штрафы, голосует, пишет обращения.
- Чиновник (своей страны): рассматривает заявления, выписывает штрафы и налоги, ведёт розыск.
- Президент (своей страны): всё, что может чиновник, плюс указы и новости, выборы, выдача псякоинов гражданам своей страны, назначение чиновников.
- Суперадмин: роли, баны, балансы любых игроков, все страны, журнал аудита.

## Этапы
1. **Каркас.** Next.js, Tailwind, shadcn, Prisma, Neon, ESLint/Prettier, Vitest, Playwright, CI. Seed стран и суперадмина. Пустой деплой на Vercel.
2. **Аккаунты и оболочка.** Регистрация по коду-приглашению, вход и выход, сессии, шапка в стиле Госуслуг, переключатель RU/PSY, `lib/lore` с тестами.
3. **Гражданство и очередь заявлений.** Реестр услуг, каталог, формы, «Мои заявления», очередь в `/gov`, одобрение и отказ с комментарием, уведомления.
4. **Документы.** Остальные услуги с документами, карточки документов в кабинете (стилизованный паспорт с гербом страны), аннулирование.
5. **Экономика и штрафы.** Журнал транзакций, пошлины и возвраты, выдача псякоинов президентом и админом, штрафы и налоги, оплата, фильтр запрещённых слов с автоштрафом.
6. **Обращения, розыск, переезд.** Письмо президенту, жалобы, доска «Разыскиваются» с должниками, Саменка, Мигрантское окно.
7. **Новости, указы, выборы.** Лента на главной, выборы (создание, кандидаты, голосование, итоги).
8. **Админка.** Пользователи, роли, баны, балансы, журнал аудита.
9. **Полировка.** Мобильная вёрстка, пустые состояния, 404 в духе лора, финальный деплой, README.

Каждый этап — отдельный коммит или серия коммитов в `claude/gifted-planck-ydloji`, с работающим деплоем после каждого.

## Проверка
- Vitest: `forbidden.ts` (все запрещённые варианты, обход через пробелы и латиницу, лорные числа проходят), `numbers.ts`/`dates.ts`, `ledger.ts` (баланс не уходит в минус, при сбое откат), `requires()` у каждой услуги.
- Playwright e2e по главному сценарию: регистрация → заявление на гражданство → вход чиновником → одобрение → у пользователя есть паспорт → заявление на загранпаспорт → президент выдаёт псякоины → оплата штрафа → попытка написать «52» даёт отказ и автоштраф → переключение на PSY показывает дату 12.34.1234.
- Проверки доступа: чиновник СШП не видит заявления Бобокаунтри, гражданин не открывает `/gov` и `/admin`.
- CI зелёный. Ручная проверка на preview-деплое Vercel.
